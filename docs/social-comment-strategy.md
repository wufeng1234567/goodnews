# 社媒评论采集方案（历史记录）

此文件是早期调研记录，最新的可执行方案、实测数据、成本/风险矩阵和实验计划请见：

[社媒完整评论采集：技术方案与实验计划](social-comment-full-plan.md)

要点回顾：

- Bilibili 公开 API + 登录 Cookie 可做完整主评论与楼中楼分页；旧版“第 3 页不足 20 条就停止”的 bug 已修复。
- 抖音评论 API 依赖页面 XHR 签名，脱离页面上下文重放不可靠；真实浏览器会话 + 滚动是当前可行路径。
- 小红书需要真实登录态；headless 容易被安全页拦截，headful Edge 能拿到评论接口首屏数据。
- DOM 解析不作为数据采集方案。
